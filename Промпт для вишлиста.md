# Приложение «Список желаний»

## Стек

- Python FastApi
- SQLite + sqlalchemy + alembic
- React
- Docker compose
- Caddy
- Tailwind CSS

## Описание

Задача разработать простое веб-приложение развёртываемое на домене iwish.bariakh.ru. Из Docker должен торчать один порт 127.0.0.1, а его проксированием будет заниматься Caddy

### Модели

*Ниже описанные, но не ограничиваясь ими*

#### Праздник

Название, эмодзи, дата, описание (не обязательно), повторять каждый год?, тип оформления (новый год день рождения итд)

#### Подарок

Название, описание (не обязательно), стоимость или диапозон (не обязательно), знак ~ у цены (bool), валюта (не обязательно), фото (не обязательно), ссылка для покупки (не обязательно), степень желания (1-5) (степень желания не видна пользователям)

У приложения 2 страницы:

### Публичная страница

Отображается предстоящий праздник, обратный отсчёт до него (отображается в реальном времени (месяцы, дни, часы, минуты, секунды) до 00:00 дня праздника по часовому поясу устройства). В день праздника конфети. Под карточкой с заголовком и отсчётом отображается список подарков на этот праздник. У в свернутом виде видна маленькая картинка и название, при раскрытии - все поля. Если у праздника выбрано оформление, то вся страница должна быть в стиле праздника. При входе по персональной ссылке, отображается приветствие с именем. При входе по персональной ссылке, обращение сохраняется в куки (как id для возможности смены имени). При заходе в куки всегда сохраняется id устройства для возможности поставить лайк на подарок. Лайкнутые подарки отображаются вверху списка. Подарки сортируются по убыванию желания

### Админ панель

Вход по паролю, управление праздниками, управление подарками. У каждого подарка можно отметить, на какие праздники его отображать. Возможность генерировать красивые qr коды с персональными ссылками, с указанием имени

## Требования

Адаптивный дизайн для всех платформ, темная/светлая тема
